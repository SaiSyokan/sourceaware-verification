# Reported Aggregate Results

These CSV files are machine-readable transcriptions of the aggregate values in manuscript Tables III-VII. They make result claims easy to audit and plot; they are not substitutes for raw predictions.

- `table_iii_zero_shot.csv`: calibration/test 8-way macro metrics
- `table_iv_supervised.csv`: 800-sample held-out supervised protocol
- `table_v_modalities.csv`: factor-level macro-F1 by available modalities
- `table_vi_framework_ablation.csv`: variants A-D
- `table_vii_module_ablation.csv`: evidence, description, and retrieval-budget analysis

Percentages are stored on the manuscript's 0-100 scale.
